1. Connect GitHub Token missing

Choose how GitHub should authenticate this add-on.

Create your own GitHub App (shows your name on GitHub's screens, needs nothing from this add-on's maintainer):

  1. Open github.com/settings/apps/new (or Settings → Developer settings → GitHub Apps → New GitHub App).
  2. Give it a name you recognize, e.g. Github Config Sync. The Homepage URL and Webhook fields are not needed (webhook can be disabled).
  3. Under Repository permissions, set Metadata: Read-only and Contents: Read and write.
  4. Under Where can this GitHub App be installed?, choose Only on this account.
  5. Tick Opt in to the device flow, then create the app.
  6. Install it on your account, choosing Only select repositories and picking the repository you will sync.
  7. Copy the Client ID from the app settings page into the field below. No client secret is needed for device flow.

Required when using a GitHub App. Overrides the default OAuth app otherwise.

4. Scheduled sync

The add-on runs in the background and syncs on the selected days at the chosen time (local time of your Home Assistant server).

Releases are tagged with dd/mm/yy hh:mm:ss format and auto-pruned to the retention count below.

How many dated auto-releases to keep on GitHub (1-100); older ones are pruned. Example: 7 keeps a week's worth of daily syncs.

Optional. If empty, the scheduler uses the server's local timezone. Home Assistant's timezone is unknown. Example: Europe/Berlin, America/New_York.

Controls how much detail is logged for GitHub and Home Assistant API calls. Below DEBUG, each request is still logged without credentials; all logs appear in the add-on log.

8. Documentation

Everything is configured from this page — nothing needs to be typed by hand. The sections above work together, left to right:

  • 1. Connect GitHub — connects the add-on to your GitHub account (your own GitHub App, the default Device Flow, or a fine-grained PAT) and saves the token.
  • 2. Repository setup — load an existing repository or create a new one (defaults to private).
  • 3. Sync scope — which files are synced, the pre-commit gate, and the log level.
  • 4. Mount points — sync whole folders such as /media, /share, /ssl.
  • 5. Recommended .gitignore — one-click ignore defaults for Home Assistant.
  • 6. Scheduled sync — automatic daily/weekly syncs at a chosen time.
  • 7. Dry run — preview what would be uploaded before anything reaches GitHub.

Full documentation (installation, option reference, scheduled sync, troubleshooting) is available on GitHub: repository README and the add-on documentation.

Sync Now runs a scan using the current settings: with Dry run enabled it only previews what would be uploaded or deleted; untick dry run and click again to push the changes to GitHub.
